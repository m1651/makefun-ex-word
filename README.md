An entry for the [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) bounty on make.fun.

## The entry

`main.py` writes exactly one word — the word my ex would use to describe me — to `/output/entry.txt`:

> Forgettable

The surprise is erasure rather than a flaw: it stings because it is painfully true and plainly owned, it lands instantly with no explanation, and it names a fear almost everyone has lived through.

## Run

```sh
python3 main.py
```
